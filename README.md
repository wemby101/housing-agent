# 🏠 청년 집 구하기 진단

계약 전에 서울 빌라(연립·다세대)의 **전·월세 위험 신호**와 **내가 받을 수 있는 청년 주거 지원**을 한 번에 보여 주는 앱입니다.
모든 숫자는 공공데이터로 코드에서 계산하고, 화면에 출처를 함께 표시합니다.

## 실행

```bash
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # 키 입력
.venv/bin/streamlit run app.py
```

테스트: `.venv/bin/pytest -q` (네트워크 없이 기록된 응답으로 실행)

## 필요한 키 (`.env`, 절대 커밋하지 않음)

| 이름 | 발급처 | 용도 |
|---|---|---|
| `JUSO_API_KEY` | business.juso.go.kr | 주소 검색 → 시군구·법정동·번지 |
| `DATA_GO_KR_KEY` | data.go.kr (일반 인증키, Decoding) | 건축물대장, 연립다세대 매매 실거래가 |
| `VWORLD_API_KEY` | vworld.kr (선택, 활용API: 국가중점) | 공동주택 공시가격 자동 조회 — 없으면 화면에서 직접 입력 |
| `VWORLD_DOMAIN` | (선택) | 브이월드 키에 등록한 서비스URL. 기본값 `localhost:8501`, 배포하면 배포 주소로 바꾸고 브이월드에도 같은 주소 등록 |

Streamlit Community Cloud에서는 Secrets에 같은 이름으로 최상위(root-level)에 넣으면 환경변수로 읽힙니다.

## 판정 규칙

| 신호 | 규칙 | 근거 |
|---|---|---|
| 보증보험 가입 불가 | 보증금 > 공시가격 × 126% − 선순위 채권 | HUG 전세보증 기준 |
| 깡통전세 위험 / 주의 | (보증금 + 선순위 채권) ÷ 추정 매매시세 ≥ 80% / 70~80% | 일반적 기준 |
| 주택 아님 | 건축물대장 주용도가 공동주택·단독주택이 아님 | 건축물대장 |

추정 시세: 최근 24개월 같은 지번 거래 2건 이상이면 그 ㎡당 가격 중앙값 × 전용면적, 아니면 같은 동·면적 ±20%·건축년도 ±5년 거래 2건 이상.
협상 목표 보증금: min(보증보험 한도, 추정 시세 × 70% − 선순위 채권).

## 데이터 출처

도로명주소 API(행정안전부) · 건축물대장 표제부(국토교통부) · 연립다세대 매매 실거래가(국토교통부) · 공동주택가격(브이월드) ·
지원 정책표 `data/policies.json` (서울주거포털·복지로·서울시 공고에서 2026-11-16 확인, 항목마다 출처 링크)
