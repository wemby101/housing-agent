# 🏠 청년 집 구하기 진단

전·월세 계약 전에 집의 **위험 신호**와 **내가 받을 수 있는 청년 주거 지원**을 한 번에 보여 주는 앱입니다.
서울·경기·인천의 빌라(연립·다세대)와 아파트가 대상입니다.
모든 숫자는 공공데이터로 코드에서 계산하고, 화면에 출처를 함께 표시합니다.

**바로 써 보기:** https://jipjikimi.streamlit.app (로그인 없음 · 예: `봉천동 1-70` → 201호 → 보증금 22000)

- **폼 진단:** 주소 검색 → 호 선택(전용면적 자동) → 보증금·월세·근저당 입력 → 위험 신호·지원 정책·해야 할 일
- **AI에게 말로 물어보기:** "봉천동 1-70 201호 전세 2억 2천인데 괜찮아? 27살 연봉 3천"처럼 물으면
  AI가 주소 검색·집 진단 도구를 직접 불러 결과를 설명합니다. AI는 도구가 계산한 숫자만 쓰고,
  안전 보증금 목표를 넘는 금액은 권하지 않습니다.
- **보증금을 낮추고 월세로 바꾸면:** 결과 화면에서 보증금을 움직이면 같은 집 데이터로 시세 대비 비율·위험 신호를 다시 계산하고,
  낮춘 보증금만큼의 월세(전월세 전환율 법정 상한 5% 기본)와 지금 조건을 나란히 보여 줍니다.
- **계약할 때 쓸 문구:** 진단 결과에 맞춘 계약서 특약(담보권 설정 금지, 보증보험 거절 시 해제, 근저당·압류 말소 등)과
  집주인·중개사에게 보낼 협상 메시지를 만들어 복사할 수 있게 합니다. 숫자는 코드가 넣고, AI는 말투만 다듬으며
  다듬은 글에서 원래 숫자가 하나라도 빠지면 쓰지 않습니다.
- **시세 근거·추이:** 추정 매매·전세 시세에 쓴 실거래(계약월·지번·면적·금액)를 표로 보여 주고, 분기별 ㎡당 매매가 그래프를 그립니다.
  최근 1년 ㎡당 중간값이 그 전 1년보다 5% 넘게 떨어졌으면 '시세 하락' 주의 신호와 1년 뒤 예상 비율을 알려 줍니다.
- **후보 집 비교:** 진단한 집을 최대 4곳까지 담아 시세 대비·보증보험·협상 목표·판정을 나란히 비교합니다.
- **전세대출을 받으면 매달 얼마?:** 대출 금액(기본: 보증금의 80%, 청년전용 버팀목 한도 1.5억)과 금리(기본 2.8%)로
  월 대출이자를 계산하고, 보증금을 낮춘 조건의 '대출이자 + 월세'와 비교해 1년 차이를 보여 줍니다.
- **집주인 확인 안내:** 공개 API가 없어 자동 조회는 하지 않고, HUG 안심전세 앱 임대인 정보 조회·세무서 미납 국세 열람·
  (신탁 등기면) 신탁원부와 수탁사 동의서를 해야 할 일 목록에 넣습니다.
- **실거래 지도:** 시세 계산에 쓴 거래를 지번별로 묶어 이 집과 함께 지도에 찍습니다 (도로명주소 좌표제공 API, 키가 없으면 브이월드. 한 번 찾은 좌표는 저장해 재사용, 데모 집 좌표는 `data/geocode_seed.json`).
- **등기부등본 PDF**를 올리면 근저당·압류 등을 읽어 자동으로 채웁니다.
- 결과를 **HTML 파일로 저장**하거나 **링크로 공유**할 수 있습니다 (나이·소득은 링크에 넣지 않음).

## 실행

```bash
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # 키 입력
.venv/bin/streamlit run app.py
```

테스트: `.venv/bin/pytest -q` (네트워크 없이 기록된 응답으로 실행)

## 판정 규칙

| 신호 | 규칙 | 근거 |
|---|---|---|
| 보증보험 가입 불가 | 보증금 > 공시가격 × 126% − 선순위 채권 (아파트는 HUG가 KB 시세를 먼저 써서 '주의') | HUG 전세보증 기준 |
| 깡통전세 위험 / 주의 | (보증금 + 선순위 채권) ÷ 추정 매매시세 ≥ 80% / 70~80% | 일반적 기준 |
| 시세 의심 | 추정 시세가 공시가격의 2배 초과 → 비율 계산에서 제외 | 공시가격은 보통 시세의 60~70% |
| 주변 전세보다 비쌈 | 보증금 > 주변 전세 시세 × 110% (전세 계약만) | 국토교통부 전월세 실거래가 |
| 주택 아님 / 상가 혼재 | 건축물대장 주용도가 공동주택·단독주택이 아님 | 건축물대장 |
| 등기부 위험 기록 | 압류·가압류·가처분·경매·신탁 | 업로드한 등기부등본 |

- **추정 매매시세:** 최근 24개월 같은 지번 거래 3건 이상이면 그 ㎡당 가격 중앙값 × 전용면적, 아니면 같은 동·면적 ±20%·건축년도 ±5년 거래 3건 이상.
- **주변 전세 시세:** 같은 방식, 최근 12개월 신규 전세 계약만 (월세·갱신 계약 제외).
- **협상 목표 보증금:** min(보증보험 한도, 추정 시세 × 70% − 선순위 채권).
- **지원 정책 중위소득·재산:** '부모와 따로 살아요'를 체크하면 연소득 ÷ 12를 2026년 기준 중위소득(1인 256만 4,238원, 부부 419만 9,292원)과 비교하고,
  '재산 1.2억 원 이하·자동차 2,500만 원 미만'을 체크하면 재산 조건을 충족으로 봅니다. 체크하지 않으면 정책에서 빼지 않고 '추가 확인 필요'로 둡니다.
- 건축물대장이 없거나 조회에 실패하면 같은 지번의 아파트 거래로 아파트 여부를 판단합니다.

## 발표용 예비 응답

공공 API가 실패하면(403·503·시간 초과) `data/demo/`에 기록해 둔 응답으로 대신합니다 (데모 3곳: 봉천동 빌라·송도 아파트·분당 아파트).
배포 서버(Streamlit Community Cloud)는 해외에 있어 브이월드(공시가격·호 목록) 접속이 막힙니다.
그래서 배포판에서는 데모 3곳만 기록 응답으로 공시가격이 나오고, 다른 집은 공시가격을 직접 입력합니다 (실거래가·건축물대장·주소 검색·지도 좌표는 실시간). 지도 좌표는 도로명주소 좌표제공 API로 찾습니다 (0.5초 간격 호출 — 1초에 11번 넘게 부르면 5초 막힘).
다시 기록: `.cache/*.json`을 지우고 `DEMO_RECORD=1 PYTHONPATH=. .venv/bin/python scripts/record_demo.py`. 키는 저장하지 않습니다.
